# String Calculator TDD Kata (Dart)

A simple String Calculator built using **Test-Driven Development (TDD)** principles in Dart.

## 🛠 Features
- Handles empty strings (returns 0).
- Supports single and multiple numbers.
- Supports new line (`\n`) as a delimiter.
- Supports custom delimiters using the `//[delimiter]\n` syntax.
- Throws an exception for negative numbers, listing all negatives found.

## How to Run Tests
To verify the implementation, run the following command in your terminal:

```bash
flutter test
